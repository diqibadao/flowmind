支持与反馈

遇到问题、想提需求，直接开 Issue，我会看。

FlowMind 没有账号体系，也没有工单系统——所有反馈都在公开仓库里，可被搜索、可被追踪。

1. 报告问题

请附上三样东西，能大幅加快定位：

  • 版本：FlowMind → 设置 → 关于
  • 你做了什么：从打开应用到出问题的步骤
  • 期望 vs 实际

→ 提交 Bug 报告　→ 提功能建议

2. 接入 MCP（让 AI 帮你画图）

在 FlowMind 里打开 设置 → MCP，点「复制接入提示词」，粘进任意 Agent（Claude Code / Codex / Cursor 等）的对话框即可。它会自己安装、注册，并画一张测试图确认落地。

手动配置时，服务命令是：

npx -y https://github.com/diqibadao/flowmind/releases/download/v0.7.0/flowmind-mcp-0.7.0.tgz

3. 常见问题

图库里看不到刚生成的图？
确认 Agent 写入的是你在设置里选择的图库文件夹；也可以在图库视图里刷新一次。

版本历史一直是空的？
先确认已升级到最新版本；仍有问题请开 Issue 并附系统版本。

MCP 连不上？
先在终端手动执行上面的命令并观察报错，再把报错原文贴进 Issue。

AI 用不了？
检查模型配置（OpenAI 兼容地址 / 本机 Ollama 是否在运行），密钥是否已保存。

数据存在哪？
你的图就是你选的那个文件夹里的普通文件；应用设置与草稿在系统沙盒目录内。

4. 安全与隐私问题

涉及安全的问题请不要在公开 Issue 里写细节，先通过 Issues 留一句「有一个安全问题，希望私下沟通」。

Support

Found a bug or want a feature? Open an issue — I read them.

FlowMind has no accounts and no ticket system — all feedback lives in the public repository, searchable and trackable.

1. Reporting an issue

Three things make triage much faster:

  • Version: FlowMind → Settings → About
  • What you did: steps from launching the app
  • Expected vs actual

→ Report a bug　→ Request a feature

2. MCP setup

Open Settings → MCP in FlowMind and click “Copy setup prompt”; paste it into any Agent chat (Claude Code, Codex, Cursor, …). It installs, registers and draws a test diagram by itself.

Manual server command:

npx -y https://github.com/diqibadao/flowmind/releases/download/v0.7.0/flowmind-mcp-0.7.0.tgz

3. FAQ

New diagram doesn’t show up?
Make sure the Agent wrote into the library folder you picked in Settings, then refresh the gallery.

Version history is empty?
Update to the latest build first; if it persists, open an issue with your macOS version.

MCP won’t connect?
Run the command above manually in a terminal and paste the error into an issue.

AI doesn’t work?
Check the model configuration (OpenAI-compatible endpoint, or that local Ollama is running) and whether the key is saved.

Where is my data?
Your diagrams are ordinary files in the folder you chose; settings and drafts live in the sandbox container.

4. Security & privacy

For security reports, do not post details publicly — open an issue saying “security issue, would like a private channel”.
