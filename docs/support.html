接入 MCP（让 AI 帮你画图）

在 FlowMind 的「设置 → MCP」里点「复制接入提示词」，粘进任意 Agent 的对话框即可；它会自己安装、注册、跑一张测试图。

手动接入时，服务命令是：

npx -y https://github.com/diqibadao/flowmind/releases/download/v0.7.0/flowmind-mcp-0.7.0.tgz

常见问题

图库里看不到我刚生成的图？确认 Agent 写入的是你在设置里选的图库目录；也可以在图库里点一次刷新。

版本历史一直是空的？更新到最新版本后仍为空，请开 Issue 并附上系统版本。

MCP 连不上？先在终端手动跑一次上面的命令，看报错；再把报错贴进 Issue。

MCP setup (let an Agent draw)

In FlowMind, open Settings → MCP and click “Copy setup prompt”; paste it into any Agent chat. It installs, registers and runs a test diagram by itself.

Manual server command:

npx -y https://github.com/diqibadao/flowmind/releases/download/v0.7.0/flowmind-mcp-0.7.0.tgz

FAQ

My new diagram doesn’t show up? Make sure the Agent wrote into the library folder you picked in Settings, then refresh the gallery.

Version history stays empty? If you are on the latest build and it is still empty, open an issue with your macOS version.

MCP won’t connect? Run the command above manually in a terminal, then paste the error into an issue.
