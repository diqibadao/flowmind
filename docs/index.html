FlowMind

把流程画对，而不是只画出来

FlowMind 是一款面向 macOS 的流程图与思维导图工具：结构化图形、智能布局、AI 帮你改图，数据始终在你自己手里。

图是真的对象 —— 正交连线、泳道、ER、思维导图，不是图片；能选中、能改、能对齐。

你的图放在自己的文件夹里

选择一个文件夹作为图库，所有图和普通文件一样躺在 Finder 里——可以备份、可以 git、可以直接发给同事。

让 AI 帮你画

接入任意 MCP 客户端（Claude Code、Codex、Cursor 等），一句话生成可编辑的流程图：

npx -y https://github.com/diqibadao/flowmind/releases/download/v0.7.0/flowmind-mcp-0.7.0.tgz

详细接入方式见 支持页。

Diagrams you can actually edit

FlowMind is a macOS flowchart and mind-map tool: real structured shapes, smart layout, AI that edits your canvas — and your files stay yours.

Diagrams are real objects — orthogonal routing, swimlanes, ER tables, mind maps. Select them, edit them, align them — not a picture.

Your diagrams live in a folder you choose

Pick a folder as your library. Every diagram is a plain file in Finder — back it up, put it in git, send it to a colleague.

Let an Agent draw for you

Works with any MCP client (Claude Code, Codex, Cursor, …):

npx -y https://github.com/diqibadao/flowmind/releases/download/v0.7.0/flowmind-mcp-0.7.0.tgz

See the support page for setup details.
