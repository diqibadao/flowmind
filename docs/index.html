让 Agent 帮你画

接到任意 MCP 客户端，一句话生成可编辑的图。

npx -y https://github.com/diqibadao/flowmind/releases/download/v0.7.0/flowmind-mcp-0.7.0.tgz
1
复制提示词
FlowMind → 设置 → MCP → 「复制接入提示词」
2
粘给 Agent
Claude Code / Codex / Cursor 等任意客户端
3
等它说完「成功了」
它会自己安装、注册、画测试图，并确认文件落进了你的图库

隐私是设计出来的，不是写出来的

没有账号，没有遥测，没有分析 SDK。

数据不出本机

图就是你的文件。设置与草稿在应用沙盒里，AI Key 只进钥匙串。

AI 由你决定

只有你主动使用时才发请求，且发往你自己配置的模型服务；用 Ollama 完全不出本机。

备份可选

iCloud 备份副本默认关闭，开启后由 macOS 负责传输与加密，我们不运营任何服务器。

Three things that are different

Not “another drawing app” — three concrete choices.

◈

Real objects

Orthogonal routing, anchor snapping, swimlanes, ER tables, mind maps — selectable, editable, alignable. Not a screenshot.

▤

Your files stay yours

Your library is a folder you choose. Visible in Finder — back it up, put it in git, send it to a colleague.

✦

AI shows the diff first

Changes are previewed before they touch the canvas. Every edit is undoable and versioned.

Let an Agent draw for you

Works with any MCP client.

npx -y https://github.com/diqibadao/flowmind/releases/download/v0.7.0/flowmind-mcp-0.7.0.tgz
1
Copy the setup prompt
FlowMind → Settings → MCP
2
Paste it to your Agent
Claude Code, Codex, Cursor, anything with MCP
3
Wait for “done”
It installs, registers and draws a test diagram into your library

Privacy by design

No account. No telemetry. No analytics SDKs.

Data stays local

Diagrams are your files; settings live in the sandbox; AI keys live in the Keychain.

AI on your terms

Requests go only to the model service you configured. With Ollama, nothing leaves your Mac.

Backup is opt-in

iCloud backup is off by default; when on, Apple handles transport and encryption. We run no servers.
