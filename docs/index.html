个人图库

缩略图网格、搜索、收藏、回收站；10+ 套模板，还能把任何一张图存成「我的模板」。

AI 接入

1
复制提示词
FlowMind → 设置 → MCP → 「复制接入提示词」
2
粘给 Agent
Claude Code / Codex / Cursor 等任意客户端
3
等它说完「成功了」
它会自己安装、注册、画测试图，并确认文件落进了你的图库

隐私是设计出来的，不是写出来的

没有账号，没有遥测，没有分析 SDK。

数据不出本机

图就是你的文件。设置与草稿在应用沙盒里，AI Key 只进钥匙串。

AI 由你决定

只有你主动使用时才发请求，且发往你自己配置的模型服务；用 Ollama 完全不出本机。

备份可选

iCloud 备份副本默认关闭，开启后由 macOS 负责传输与加密，我们不运营任何服务器。

Seven things it does

Not just “it can draw” — it keeps what you drew.

🗂

Personal library

Thumbnail grid, search, favourites, trash; 10+ templates, and any diagram can become one of your own.

💾

Local storage

Diagrams are ordinary files in a folder you choose — open in Finder, back up, send to a colleague.

☁️

iCloud backup

Optional: each save copies the file into iCloud Drive. Apple handles transport and encryption; saving works offline.

🤖

AI built in

Generate, edit, optimise, write docs — OpenAI-compatible or local Ollama; keys stay in the Keychain.

🔌

MCP / Agents

Claude Code, Codex, Cursor create editable diagrams that land in your library, tagged as Agent-made.

🕘

Git version history

Every save is a commit; manual versions are kept forever, and you can annotate them.

🔍

Compare & roll back

Three-colour diff — green added, red removed, blue changed, connectors included. Restore any version in one click.

Privacy by design

No account. No telemetry. No analytics SDKs.

Data stays local

Diagrams are your files; settings live in the sandbox; AI keys live in the Keychain.

AI on your terms

Requests go only to the model service you configured. With Ollama, nothing leaves your Mac.

Backup is opt-in

iCloud backup is off by default; when on, Apple handles transport and encryption. We run no servers.
