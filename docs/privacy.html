隐私协议

生效日期：2026 年 10 月 25 日 · 最后更新：2026 年 10 月 25 日 · 适用于 FlowMind App、MCP 工具与本网站

一句话：我们不收集你的任何数据。没有账号，没有遥测，没有分析，没有广告 SDK，我们没有服务器可以存放你的图。

1. 这份协议管什么

适用于三样东西：macOS 上的 FlowMind 应用、随应用使用的 MCP 工具（flowmind-mcp），以及本介绍网站。

2. 我们收集什么

什么也不收集。具体地说，我们不收集、不上传、不存储：

  • 你的图、文字、文件名、文件夹结构
  • 你的使用行为、点击、停留时长
  • 设备型号、系统版本、安装 ID、崩溃堆栈
  • 任何联系方式（除非你主动在 GitHub Issues 里公开）

应用内不包含任何统计分析、广告或第三方追踪 SDK。

3. 数据存在哪里

数据位置谁能访问
流程图 / 思维导图你在设置里选的图库文件夹（或你另存为的位置）只有你；就是普通文件
应用设置、草稿、图库缩略图macOS 应用沙盒容器内只有你
AI 服务密钥macOS 钥匙串（Keychain）只有你
本地诊断日志应用沙盒容器内 logs/只有你；不上传

4. 本地日志（如实说明）

为了排查界面异常，应用会把前端报错写入本机的 logs/frontend.log：单条不超过 2KB，文件不超过 1MB，超出滚动覆盖，内容仅包含错误信息与堆栈。这些日志不会离开你的电脑，也不会自动发送给任何人。你可以在 Finder 里直接删除它们。

5. iCloud 备份（可选，默认关闭）

开启后，每次保存会把当前文件复制一份到 iCloud Drive 中 FlowMind 的文件夹，作为备份副本。传输与静态加密由 Apple 负责，我们没有服务器、也无法访问这些文件。本地文件始终是唯一真身；断网、未登录时保存照常工作。

6. AI 功能会发送什么

只有当你主动使用 AI 功能（生成、改图、优化、文档）时：

  • 发送内容是：你在对话框里输入的文字，以及当前图的相关内容
  • 接收方是：你自己配置的模型服务（OpenAI 兼容接口的地址与模型），或你本机的 Ollama
  • 我们不运营任何中转或代理服务器，也不记录你的请求
  • 使用 Ollama 时，数据不会离开你的电脑

请注意：你选择的模型服务商如何处理这些内容，受他们自己的隐私政策约束。

7. MCP 工具与 Agent

flowmind-mcp 是运行在你电脑上的本地程序，Agent 通过它把图写进你的图库：

  • 只用本机标准输入输出通信，不开放任何网络端口
  • 只在你在设置里指定的图库目录内读写，越界路径会被直接拒绝
  • 不收集、不上报任何信息

是你在 Agent 里下的指令决定它写什么；FlowMind 不参与、也看不到你与 Agent 的对话。

8. 应用何时联网

只有两种情况：① 你主动使用 AI 功能时，连接你配置的模型服务；② 你开启 iCloud 备份时，由 macOS 连接 iCloud。除此之外，应用在离线状态下功能完整。

9. 系统权限

  • 文件访问：只访问你在系统面板里主动选择的文件或文件夹（通过 macOS 安全作用域书签记住授权）
  • 钥匙串：用于保存你自己填写的 AI 密钥
  • 我们不使用相机、麦克风、通讯录、定位、剪贴板读取等权限

10. 第三方组件

应用中包含若干开源库（清单可在「设置 → 关于 → 开放源代码许可」查看）。它们在本机运行，不涉及数据外传。我们不含任何商业分析或广告组件。

11. 你的权利

因为数据都在你自己的电脑上，所以：

  • 访问 / 导出：图库文件夹里的文件直接可用
  • 删除：删掉文件、清空应用数据目录即可，彻底删除
  • 撤回：关闭 iCloud 备份，或清空 AI 密钥

我们手上没有任何副本，因此也无法替你导出或删除——这正是本地优先的含义。

12. 数据保留

我们不保留任何数据。你本机上的文件由你决定保留多久。

13. 儿童

本应用不面向 13 岁以下儿童，也不收集任何个人信息。

14. 跨境传输

我们不进行任何数据传输。若你使用云端 AI 服务，数据由该服务商按其所在地与条款处理。

15. 协议变更

如果本协议有实质变化，我们会更新本页顶部的日期，并在 GitHub 仓库中留存提交记录。

16. 联系我们

通过 GitHub Issues 与我们联系。涉及安全问题的报告，请避免公开细节，先私下说明。

Privacy Policy

Effective: October 25, 2026 · Last updated: October 25, 2026 · Covers the FlowMind app, the MCP tool, and this website

In one sentence: we collect nothing. No account, no telemetry, no analytics, no ad SDKs — and we run no servers that could hold your diagrams.

1. Scope

This policy covers the FlowMind macOS app, the bundled MCP tool (flowmind-mcp), and this website.

2. What we collect

Nothing. Specifically, we do not collect, upload or store:

  • Your diagrams, text, file names or folder structure
  • Usage behaviour, clicks or time spent
  • Device model, OS version, install ID or crash stacks
  • Contact details (unless you post them publicly in GitHub Issues)

The app contains no analytics, advertising or third-party tracking SDKs.

3. Where data lives

DataLocationAccess
DiagramsThe library folder you chose (or wherever you save)Only you — they are ordinary files
Settings, drafts, thumbnailsInside the macOS app sandbox containerOnly you
AI keysmacOS KeychainOnly you
Local diagnostics loglogs/ inside the sandbox containerOnly you — never uploaded

4. Local logs (full disclosure)

To help diagnose UI errors, the app writes front-end errors to logs/frontend.log on your machine: each entry ≤ 2KB, file ≤ 1MB, rolling. These logs never leave your Mac and are never sent automatically. You can delete them in Finder.

5. iCloud backup (optional, off by default)

When enabled, each save copies the file into FlowMind's folder in iCloud Drive as a backup copy. Apple handles transport and encryption at rest; we run no servers and cannot access these files. The local file is always the original. Saving works offline and when signed out.

6. What AI features send

Only when you actively use an AI feature (generate, edit, optimise, document):

  • What is sent: your typed input plus the relevant part of the current diagram
  • Where it goes: the model service you configured yourself (an OpenAI-compatible endpoint), or a local Ollama instance
  • We operate no relay or proxy and keep no request records
  • With Ollama, data never leaves your Mac

Your chosen model provider processes that content under their own privacy policy.

7. The MCP tool and Agents

flowmind-mcp runs locally so an Agent can write diagrams into your library:

  • Communicates only over local stdio — opens no network ports
  • Reads and writes only inside the library folder you specified; out-of-scope paths are rejected
  • Collects and reports nothing

What it writes is determined by the instructions you give your Agent; FlowMind neither sees nor participates in that conversation.

8. When the app uses the network

Only two cases: (1) you actively use an AI feature — it connects to the model service you configured; (2) you enable iCloud backup — macOS connects to iCloud. Otherwise the app is fully functional offline.

9. System permissions

  • Files: only what you pick in a system panel (access is remembered via a macOS security-scoped bookmark)
  • Keychain: to store the AI key you enter
  • We do not use camera, microphone, contacts, location or clipboard reading

10. Third-party components

The app bundles several open-source libraries (see Settings → About → Open-source licenses). They run locally and transmit nothing. No commercial analytics or ad components are included.

11. Your rights

  • Access / export: the files in your library folder are directly usable
  • Erasure: delete the files and clear the app data directory — that is complete deletion
  • Withdraw: disable iCloud backup, or clear your AI key

We hold no copies, so we cannot export or delete on your behalf — that is what local-first means.

12. Retention

We retain nothing. How long files stay on your Mac is up to you.

13. Children

Not directed to children under 13; we collect no personal information.

14. International transfers

We transfer nothing. If you use a cloud AI provider, that provider processes data under its own terms and jurisdiction.

15. Changes

If this policy changes materially, the date above is updated and the commit history in the GitHub repository keeps the record.

16. Contact

Reach us via GitHub Issues. For security reports, avoid posting details publicly and describe the issue first.
