隐私协议

最后更新：2026 年 10 月 25 日

一句话：FlowMind 不收集你的任何数据。没有账号，没有遥测，没有分析，没有第三方追踪 SDK。

1. 我们不收集什么

我们不收集、不上传、不存储你的图、文本、文件名、使用行为、设备信息或崩溃日志。App 内没有任何分析或广告 SDK。

2. 你的数据在哪里

  • 图文件：保存在你选择的「图库文件夹」里，或你另存为的位置。它们就是普通文件，归你所有。
  • 设置与草稿：保存在本机的应用数据目录（macOS 沙盒容器内）。
  • AI 密钥：只保存在 macOS 系统钥匙串（Keychain），不写进任何配置文件、日志或导出文件。

3. iCloud 备份（可选，默认关闭）

你可以开启「备份副本」：保存后由 macOS 把文件复制到 iCloud Drive 里 FlowMind 的文件夹。传输与静态加密由 Apple 负责，我们没有服务器、无法访问这些文件。本地文件始终是唯一真身。

4. AI 功能会发送什么

只有当你主动使用 AI 功能时，你输入的内容与当前图的相关内容才会发送到你自己配置的模型服务（OpenAI 兼容接口，或本机的 Ollama）。我们不经过、也不运营任何中转服务器。若使用本机 Ollama，数据不离开你的电脑。

5. Agent / MCP 工具

MCP 工具运行在你自己的电脑上，仅通过本机标准输入输出通信，不开放网络端口；它只在你指定的图库目录内读写文件。

6. 你的权利

因为数据都在你自己的电脑上，删除即彻底删除：删掉图库文件夹里的文件、清空 App 数据目录即可。我们没有任何副本可供导出或删除。

7. 儿童

本应用不面向 13 岁以下儿童，也不收集任何个人信息。

8. 变更与联系

本协议若更新，会修改本页顶部的日期。如有疑问，请通过 GitHub Issues 联系。

Privacy Policy

Last updated: October 25, 2026

In one sentence: FlowMind collects nothing. No accounts, no telemetry, no analytics, no third-party tracking SDKs.

1. What we do not collect

We do not collect, upload or store your diagrams, text, file names, usage behaviour, device information or crash logs. The app contains no analytics or advertising SDKs.

2. Where your data lives

  • Diagram files: in the library folder you chose, or wherever you save them. They are ordinary files that belong to you.
  • Settings and drafts: in the local app data directory (the macOS sandbox container).
  • AI keys: stored only in the macOS Keychain — never in configuration files, logs or exports.

3. iCloud backup (optional, off by default)

You may enable backup copies: after saving, macOS copies the file into FlowMind's folder in iCloud Drive. Transport and encryption at rest are handled by Apple. We run no servers and cannot access these files. The local file is always the original.

4. What AI features send

Only when you actively use an AI feature, your input and the relevant part of the current diagram are sent to the model service you configured yourself (an OpenAI-compatible endpoint, or a local Ollama instance). We operate no proxy or relay. With Ollama, data never leaves your Mac.

5. Agent / MCP tool

The MCP tool runs on your own machine, communicates only over local stdio, opens no network ports, and reads/writes files only inside the library folder you specified.

6. Your rights

Because all data stays on your computer, deleting it is complete: remove the files from your library folder and clear the app data directory. We hold no copies to export or delete.

7. Children

This app is not directed to children under 13 and collects no personal information.

8. Changes and contact

If this policy changes, the date above will be updated. Questions? Reach us via GitHub Issues.
